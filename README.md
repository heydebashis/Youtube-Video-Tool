# Video Preview Cutter (Local)

A simple Node.js/Express tool to cut a 4-second preview from a YouTube URL.

## Setup & Run Locally

1. Unzip the project:
   ```
   unzip video_preview_cutter_local.zip
   ```
2. Change into its directory:
   ```
   cd video_preview_cutter_local
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   npm start
   ```
5. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
6. Paste a YouTube URL and start time (mm:ss), click **Cut Preview**, watch the spinner, then see the clip + download link.

---

No external hosting needed—runs entirely on your machine!
